## テスト環境・実行方法

### 環境

- **フレームワーク**: Playwright
- **テストデータ**: `e2e/fixtures/test-data.ts`
- **認証セットアップ**: `e2e/auth.setup.ts`
- **テストユーザー**: `e2e-test@example.com` / `TestPassword123!`

### 実行コマンド

```bash
# 全テスト実行
pnpm test:e2e

# UIモード（推奨：開発時）
pnpm test:e2e:ui

# ヘッドモード（ブラウザ表示）
pnpm test:e2e:headed

# デバッグモード
pnpm test:e2e:debug

# 特定のユースケースのみ
pnpm exec playwright test e2e/specs/auth/
```

### CI/CD

- **トリガー**: PR作成、main/masterへのpush
- **ワークフロー**: `.github/workflows/ci.yml`
- **前処理**:
  1. Supabaseローカル起動
  2. テストユーザー作成（SQL実行）
  3. Playwrightブラウザインストール
