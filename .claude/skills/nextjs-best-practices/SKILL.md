# Next.js Best Practices Skill

Enforce Next.js App Router (React Server Components) best practices based on comprehensive principles and patterns.

## Purpose

Guide implementation following Next.js v15+ App Router best practices:
- Server Components-first data fetching
- Tree-based UI decomposition
- Container/Presentational pattern
- Request optimization (Memoization & DataLoader)
- Proper caching strategies

## Usage

When implementing Next.js features:
1. Review PRINCIPLES.md for core design philosophy
2. Consult PATTERNS.md for specific implementation patterns
3. Reference detailed chapters via REFERENCE.md when needed

## Target Version

- Next.js: v15+
- React: v19+ (with RSC support)
- Focus: App Router (not Pages Router)
