# ユビキタス言語辞書

**Coffee Collections アプリケーション**

> 開発者とドメインエキスパートが共有する用語の定義と使用ガイド

**最終更新**: 2026-01-30
**管理者**: 開発チーム

---

## 📖 はじめに

### この辞書の目的

- チーム全体で統一された用語を使用する
- コード、UI、会話、ドキュメントで一貫性を保つ
- よくある誤用を防ぐ
- 新規メンバーのオンボーディングを支援

### 使い方

1. 新機能開発前に関連用語を確認
2. コードレビュー時の用語チェック
3. UI文言作成時の参照
4. ドメインエキスパートとの会話で使用

## 📚 コアエンティティ

### Coffee Evaluation

| 項目 | 内容 |
|------|------|
| **単語** | コーヒー評価 |
| **英語（コード）** | CoffeeEvaluation / coffee_evaluations |
| **よくある間違い** | ✗ コーヒー記録、コーヒーメモ、レビュー |
| **プロダクト内文言** | 評価、コーヒー評価 |
| **タグ** | #エンティティ #集約ルート |
| **意味** | ユーザーがコーヒー体験を記録した評価記録。店舗情報、豆情報、4つの評価値、公開設定を含む。 |
| **モデル名** | `CoffeeEvaluation` (entity.ts) |
| **関連モデル** | ShopInfo, BeanInfo, Rating, Visibility |

**ビジネスルール**:
- 評価は特定のユーザーに所属する
- 所有者のみが編集・削除できる
- 公開/非公開を切り替えられる

**使用例**:
```typescript
// ✓ 正しい
const evaluation = await CoffeeEvaluation.create(input)
const myEvaluations = await getMyEvaluations()

// ✗ 避ける
const review = await createReview()  // "Review"は使わない
const memo = await getCoffeeMemos()  // "Memo"は使わない
```

## 📝 値オブジェクト

### Shop Info

| 項目 | 内容 |
|------|------|
| **単語** | 店舗情報 |
| **英語（コード）** | ShopInfo / shop_name |
| **よくある間違い** | ✗ 店情報、カフェ情報、ストア情報 |
| **プロダクト内文言** | 店名 |
| **タグ** | #値オブジェクト |
| **意味** | コーヒーを購入・飲食した店舗の情報。店名のみを保持。 |
| **モデル名** | `ShopInfo` (shop-info.ts) |
| **関連モデル** | CoffeeEvaluation |

**制約**:
- 255文字以内
- オプショナル（空文字列可）
- トリミング処理される

**使用例**:
```typescript
// ✓ 正しい
ShopInfo.create("スターバックス 渋谷店")
ShopInfo.empty()  // 店舗未設定

// ✗ 避ける
"店舗: スターバックス"  // プレフィックス不要
```

### Bean Info

| 項目 | 内容 |
|------|------|
| **単語** | 豆情報 |
| **英語（コード）** | BeanInfo / bean_name, bean_type, roast_level |
| **よくある間違い** | ✗ コーヒー豆情報、Bean、ビーン情報 |
| **プロダクト内文言** | 豆の名前、産地、焙煎度 |
| **タグ** | #値オブジェクト |
| **意味** | コーヒー豆に関する情報。名前（必須）、産地、焙煎度を含む。 |
| **モデル名** | `BeanInfo` (bean-info.ts) |
| **関連モデル** | CoffeeEvaluation |

**サブプロパティ**:

#### Bean Name（豆の名前）
- **必須**: はい
- **制約**: 255文字以内、空文字列不可
- **例**: "エチオピア イルガチェフェ G1", "ブラジル サントス No.2"

#### Bean Type（産地）
- **必須**: いいえ
- **制約**: 255文字以内
- **例**: "エチオピア", "コロンビア", "ブレンド"
- **よくある間違い**: ✗ Origin（英語では使わない）

#### Roast Level（焙煎度）
- **必須**: いいえ
- **制約**: 100文字以内
- **選択肢**: light, cinnamon, medium, high, city, full_city, french

**使用例**:
```typescript
// ✓ 正しい
beanInfo.beanName  // "豆の名前"を取得
beanInfo.beanType  // "産地"を取得
beanInfo.roastLevel  // "焙煎度"を取得

// ✗ 避ける
beanInfo.name      // 曖昧
beanInfo.origin    // "origin"は使わない
beanInfo.type      // "産地"を指すときは"beanType"
```

### Roast Level

| 項目 | 内容 |
|------|------|
| **単語** | 焙煎度 |
| **英語（コード）** | roastLevel / roast_level |
| **よくある間違い** | ✗ 焼き加減、ロースト度、焙煎レベル |
| **プロダクト内文言** | 焙煎度 |
| **タグ** | #値オブジェクト #列挙型 |
| **意味** | コーヒー豆の焙煎の深さを表す。浅煎りから極深煎りまで7段階。 |
| **選択肢** | 下記参照 |

**焙煎度一覧**:

| コード値 | 日本語表示 | 英語名 | 特徴 |
|---------|-----------|--------|------|
| `light` | ライト（浅煎り） | Light Roast | 酸味が強い、フルーティー |
| `cinnamon` | シナモン（浅中煎り） | Cinnamon Roast | 酸味と甘みのバランス |
| `medium` | ミディアム（中煎り） | Medium Roast | バランスが良い |
| `high` | ハイ（中深煎り） | High Roast | 苦味とコクが出始める |
| `city` | シティ（やや深煎り） | City Roast | 苦味が強くなる |
| `full_city` | フルシティ（深煎り） | Full City Roast | しっかりとした苦味 |
| `french` | フレンチ（極深煎り） | French Roast | 強い苦味、スモーキー |

**使用例**:
```typescript
// ✓ 正しい
roastLevel: "medium"
選択: "ミディアム（中煎り）"

// ✗ 避ける
roastLevel: "中煎り"  // コード値は英語
roastLevel: "Medium"  // 大文字は使わない
```

### Rating

| 項目 | 内容 |
|------|------|
| **単語** | 評価値 |
| **英語（コード）** | Rating / rating |
| **よくある間違い** | ✗ 点数、スコア、評点、レーティング |
| **プロダクト内文言** | 評価 |
| **タグ** | #値オブジェクト |
| **意味** | 1〜10のスケールでコーヒーの特性を評価する値。整数のみ。 |
| **モデル名** | `Rating` (rating.ts) |
| **関連モデル** | CoffeeEvaluation |

**制約**:
- 範囲: 1〜10
- 型: 整数のみ
- 小数点不可

**評価項目**:

#### Acidity（酸味）

| 項目 | 内容 |
|------|------|
| **単語** | 酸味 |
| **英語（コード）** | acidity |
| **よくある間違い** | ✗ サンミ、酸っぱさ、Sourness |
| **プロダクト内文言** | 酸味 |
| **意味** | コーヒーの酸味の強さ・質を評価 |

- **低い（1-3）**: まろやか、酸味が少ない
- **中程度（4-7）**: バランスの良い酸味
- **高い（8-10）**: フルーティー、明るい酸味

#### Bitterness（苦味）

| 項目 | 内容 |
|------|------|
| **単語** | 苦味 |
| **英語（コード）** | bitterness |
| **よくある間違い** | ✗ ニガミ、苦さ、Bitter |
| **プロダクト内文言** | 苦味 |
| **意味** | コーヒーの苦味の強さを評価 |

- **低い（1-3）**: 甘み重視、ライト
- **中程度（4-7）**: 程よい苦味
- **高い（8-10）**: ビターチョコレートのような苦味

#### Aroma（香り）

| 項目 | 内容 |
|------|------|
| **単語** | 香り |
| **英語（コード）** | aroma |
| **よくある間違い** | ✗ カオリ、匂い、Smell, Fragrance |
| **プロダクト内文言** | 香り |
| **意味** | コーヒーの香りの良さ・複雑さを評価 |

- **低い（1-3）**: 香りが弱い
- **中程度（4-7）**: 良い香り
- **高い（8-10）**: 豊かで複雑な香り

#### Overall Rating（総合評価）

| 項目 | 内容 |
|------|------|
| **単語** | 総合評価 |
| **英語（コード）** | overallRating / overall_rating |
| **よくある間違い** | ✗ トータル評価、全体評価、総評 |
| **プロダクト内文言** | 総合評価 |
| **意味** | 全体的な満足度・好みを評価 |

- **低い（1-3）**: あまり好みではない
- **中程度（4-7）**: 良い、満足
- **高い（8-10）**: とても好み、また飲みたい

**使用例**:
```typescript
// ✓ 正しい
acidity: 8          // 酸味: 8/10
bitterness: 5       // 苦味: 5/10
aroma: 9            // 香り: 9/10
overallRating: 8    // 総合評価: 8/10

// ✗ 避ける
acidity: 8.5        // 小数点不可
rating: 11          // 範囲外
score: 8            // "score"は使わない
```

### Visibility

| 項目 | 内容 |
|------|------|
| **単語** | 公開設定 |
| **英語（コード）** | Visibility / is_public |
| **よくある間違い** | ✗ 表示設定、公開状態、可視性 |
| **プロダクト内文言** | 公開設定、公開/非公開 |
| **タグ** | #値オブジェクト #状態 |
| **意味** | コーヒー評価の公開/非公開状態。コミュニティフィードへの表示を制御。 |
| **モデル名** | `Visibility` (visibility.ts) |
| **関連モデル** | CoffeeEvaluation |

**状態**:

#### Public（公開）

| 項目 | 内容 |
|------|------|
| **単語** | 公開 |
| **英語（コード）** | isPublic: true |
| **絵文字** | 🌐 |
| **プロダクト内文言** | 公開 |
| **意味** | すべてのユーザーが閲覧可能 |

#### Private（非公開）

| 項目 | 内容 |
|------|------|
| **単語** | 非公開 |
| **英語（コード）** | isPublic: false |
| **絵文字** | 🔒 |
| **プロダクト内文言** | 非公開 |
| **意味** | 所有者のみが閲覧可能 |

**使用例**:
```typescript
// ✓ 正しい
isPublic: true      // 公開
isPublic: false     // 非公開
visibility.toggle() // 公開/非公開を切り替え

// ✗ 避ける
public: true        // "public"は予約語
visible: true       // "visible"は使わない
status: "public"    // 文字列ではなくboolean
```

## 🔐 権限・所有権

### Ownership

| 項目 | 内容 |
|------|------|
| **単語** | 所有権 |
| **英語（コード）** | ownership / isOwnedBy |
| **よくある間違い** | ✗ 所持権、権限、オーナーシップ |
| **プロダクト内文言** | あなたの評価 |
| **タグ** | #ドメインロジック |
| **意味** | 評価の作成者（所有者）のみが編集・削除できる権限 |

**使用例**:
```typescript
// ✓ 正しい
if (!evaluation.isOwnedBy(userId)) {
  throw new Error("この評価を編集する権限がありません")
}

// ✗ 避ける
if (!evaluation.belongsTo(userId))  // "belongsTo"は使わない
if (!evaluation.hasOwner(userId))   // "hasOwner"は使わない
```

---

### Viewability

| 項目 | 内容 |
|------|------|
| **単語** | 閲覧可能性 |
| **英語（コード）** | viewability / isViewableBy |
| **よくある間違い** | ✗ 閲覧権限、表示可能性、ビューアビリティ |
| **プロダクト内文言** | 閲覧できる評価 |
| **タグ** | #ドメインロジック |
| **意味** | 評価を閲覧できるかどうかの判定。公開評価または所有者。 |

**ルール**:
- 公開評価 → すべてのユーザーが閲覧可能
- 非公開評価 + 所有者 → 閲覧可能
- 非公開評価 + 他人 → 閲覧不可

**使用例**:
```typescript
// ✓ 正しい
if (!evaluation.isViewableBy(userId)) {
  throw new Error("この評価を閲覧する権限がありません")
}

// ✗ 避ける
if (!evaluation.canView(userId))      // "canView"は使わない
if (!evaluation.isAccessible(userId)) // "isAccessible"は使わない
```

## 📊 リポジトリ操作

### Sort Option

| 項目 | 内容 |
|------|------|
| **単語** | ソート順 |
| **英語（コード）** | EvaluationSortOption / sort |
| **よくある間違い** | ✗ 並び順、整列、ソートオプション |
| **プロダクト内文言** | 並び順 |
| **タグ** | #リポジトリ #クエリ |
| **意味** | 評価一覧の並び順を指定する |

**選択肢**:

| コード値 | 日本語表示 | 説明 |
|---------|-----------|------|
| `created_at_desc` | 新しい順 | 作成日時降順（デフォルト） |
| `created_at_asc` | 古い順 | 作成日時昇順 |
| `rating_desc` | 高評価順 | 総合評価降順 |
| `rating_asc` | 低評価順 | 総合評価昇順 |
| `shop_name_asc` | 店名昇順 | 店名 A→Z |
| `shop_name_desc` | 店名降順 | 店名 Z→A |

**使用例**:
```typescript
// ✓ 正しい
sort: "created_at_desc"  // 新しい順
sort: "rating_desc"      // 高評価順

// ✗ 避ける
sort: "newest"           // 具体的な値を使う
sort: "desc"             // フィールド名を含める
orderBy: "created_at"    // "sort"を使う
```

## 💬 会話での使用例

### ✅ 正しい会話

**開発者とPM**:
> PM: 「ユーザーが評価を作成するとき、デフォルトは公開にしたほうがいいですか？」
> 開発者: 「いえ、Visibilityのデフォルトは非公開（isPublic: false）にしています。ユーザーが明示的に公開設定を切り替えます。」

**開発者同士**:
> A: 「CoffeeEvaluationのRatingsを更新するロジックはどこにありますか？」
> B: 「UpdateEvaluationUseCaseの中で、エンティティのupdateメソッドを呼んでいます。」

**UIレビュー**:
> デザイナー: 「ここの文言は『評価を保存』でいいですか？」
> 開発者: 「『評価を作成』の方がユビキタス言語に沿っています。UpdateEvaluationの場合は『評価を更新』です。」

### ❌ 避けるべき会話

**技術用語の混在**:
> ❌ 「データベースのevaluationsテーブルにrating_scoreカラムを追加します」
> ✅ 「コーヒー評価に総合評価（overall_rating）を追加します」

**ドメイン外の用語**:
> ❌ 「このレビューを公開にしてください」
> ✅ 「この評価を公開にしてください」

**曖昧な表現**:
> ❌ 「点数は1から10です」
> ✅ 「評価値（Rating）は1〜10のスケールです」
